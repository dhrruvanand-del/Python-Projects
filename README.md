# 🔤 Custom Interpreted Programming Language & REPL

A lightweight, fully functional programming language and REPL (Read-Eval-Print Loop) built entirely from scratch in **Python**. This project implements the core fundamentals of compiler design: a **Lexer** (tokenizer), a **Parser** (Recursive Descent AST builder), and an **Interpreter** (AST visitor and environment manager).

![Python](https://img.shields.io/badge/Python-3.x-blue?style=flat-square&logo=python&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green?style=flat-square)

---

## ✨ Features

* **Lexical Analysis (Tokenizer):** Converts raw source code strings into a structured stream of tokens, supporting keywords, identifiers, numeric literals, strings, and comparison/arithmetic operators.
* **Abstract Syntax Tree (AST) Parser:** Employs recursive descent parsing to construct a strict syntax hierarchy, handling order of operations and control blocks.
* **Execution Environment & Scope:** Manages dynamic symbol tables, variable assignment (`let`), and local/global scoping.
* **Control Flow & Statements:** Supports conditional branching (`if`) and iterative loops (`while`), alongside native `print` utilities.
